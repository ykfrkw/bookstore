# bookstore — 地元で買う

Amazon の書籍ページから、**大学生協**（研究費／私費の指定つき）または
**地元書店**への注文メール下書きを作ります。Chrome 拡張とローカルページの
両方で動きます。

自動発注はしません。人が最終確認して送るための下書きを作るところで止めます。

## クイックスタート

```bash
npm test          # 25 件のテスト。ネットワーク不要
npm run local     # ローカル版を http://localhost:8787 で開く
```

### Chrome 拡張として使う

```bash
npm run sync
```

そのあと `chrome://extensions` を開き、デベロッパーモードを有効にして
「パッケージ化されていない拡張機能を読み込む」で **`src/adapters/extension`**
を指定します。

初回は拡張の「設定」から、氏名・所属・宛先メールアドレス・財源を入れてください。
入力内容はブラウザ内にのみ保存され、外部には送信されません
（外部通信は書誌取得のための openBD への ISBN 問い合わせのみ）。

### 使い方

1. Amazon の書籍ページを開くと、購入ボックスの上にパネルが出ます
2. 注文先（生協／地元書店）と支払区分（研究費／私費）、冊数を選びます
3. 「注文メールを作る」でメーラーが開きます
   - 和文は mailto の長さ制限を超えるため、本文はクリップボードにコピーされます。
     開いたメールに貼り付けてください
4. 複数冊まとめたいときは「まとめる」を押してから、ツールバーのアイコン →
   「1 通にまとめてメール」

生協の公費 WEB フォームから出す場合は、「備考欄をコピー」で
財源・予算代表者・配達先の 1 行が取れます。

## ローカル版

拡張を入れずに使う版です。Amazon の URL でも ISBN でも、1 行 1 件で
貼り付ければ同じ注文メールを作れます。

```bash
npm run local
```

`file://` で直接開くと ES module が CORS で弾かれるので、必ず上記コマンド
（http 経由）で開いてください。

## 開発

```bash
npm run dev       # src/core の変更を拡張ディレクトリへ自動同期
npm test
npm run build     # dist/bookstore-<version>.zip
```

ロジックは `src/core/` に集約してあり、Chrome 拡張とローカルページは
そこに薄い UI をかぶせているだけです。`src/core/` を編集したら
`npm run sync`（または `npm run dev`）を忘れずに。

詳しくは:

- **`CLAUDE.md`** — 開発規約と、踏んではいけない罠
- **`SPEC.md`** — 設計判断の根拠、データモデル、未決事項、ロードマップ
- **`docs/research.md`** — 大学生協・書店ルートの実態調査（2026-08 時点）
